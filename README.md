# StockMarketSimulator

Система сбора и обработки котировок с нескольких бирж в реальном времени.

## Имитатор биржи

| Биржа | Формат | Особенности |
|---|---|---|
| Alpha | `{"symbol","price","qty","ts","seq"}` | JSON, время ISO-8601 |
| Beta | `{"s","p","v","t","n"}` | цена строкой, время unix-ms |
| Gamma | `["AAPL",187.3,100,1754302530,1042]` | массив без имён полей, unix-секунды |
